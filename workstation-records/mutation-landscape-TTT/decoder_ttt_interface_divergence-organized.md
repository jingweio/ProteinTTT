## 1. 立题

### 1.1 要验证的假设

预训练 ProteinMPNN 的 decoder **没有把「突变位点离 partner 多近」用起来**（摸底记录已证实）。
假设：在 test time 用一个**不需要 label** 的目标把它逼出来，排序能力会提升。

**transductive**（看得到该 assay 的 mutant 序列，**看不到 label**）、**只微调 decoder、冻结 encoder**。

### 1.2 这个实验能回答什么、不能回答什么

| | |
|---|---|
| **能回答** | 「把界面先验**训进 decoder**」是否比「**事后加一个平移**」更好 |
| **不能回答** | 界面先验本身值多少钱 —— 摸底记录已回答（LOAO +0.0648） |

**⇒ 对照臂是 rescoring 规则，不是预训练基线 0.3903。**

## 2. 框架

### 2.1 一个必须先处理的结构性问题

「最大化两组分数分布的差异」**不加约束**时，全局最优是让分数**变成界面特征的一个函数** ——
组内信息全丢。那时 Spearman 就等于「用界面特征单独当预测器」：

| 分数塌缩成 | 14-assay Spearman |
|---|---:|
| 预训练基线 | 0.3903 |
| 纯二值界面标签 | 0.2068 |
| 纯连续距离特征 | 0.2564 |

**⇒ 无约束版本的最优解比起点还差 0.13–0.18**，与已被否证的 WT-likelihood 目标是同一类失效。
所以目标必须写成**散度 + 锚**。

### 2.2 系统

```
L(θ) = pearson( w̃ , s̃ )  +  λ · ‖ s_θ − s_frozen ‖² / var(s_frozen)
       └── 散度：推向「越近界面分越低」      └── 锚：不许离预训练太远
```

| 符号 | 定义 | 训练时可见 |
|---|---|---|
| `s_θ(v)` | 微调后的分数，**与评测用的是同一个函数**（官方 BindingGYM 口径） | — |
| `s_frozen(v)` | 冻结模型的分数 | ✅ |
| `d(v)` | 突变位点到**另一个 entity** 的最小重原子距离（WT 复合物算出） | ✅ label-free |
| `w(v)` | 界面先验 = `AGG_i f(d_i)`，batch 内标准化 | ✅ label-free |
| `y(v)` | 真实 DMS_score | ❌ 训练绝不可见，只在评测用 |
| `λ` | 锚的强度，**逐 assay 扫**（用户 2026-09-12 决定） | — |

**`λ` 就是摸底记录里那个 `c` 的化身** —— 它控制「往界面方向推多远」。
`λ→∞` 回到预训练模型，`λ→0` 塌缩到 0.2564；**中间有没有峰，就是本实验要测的**。

> **优化 Pearson、评测 Spearman** 是一个代理间隙（Spearman 不可微），如实记在这里。

### 2.3 🔴 一个预先写下的理论点：L2 锚会让最优解退化回 rescoring 规则

若把 `s` 当作不受网络限制的自由变量，`L` 的最优解就是沿 `w` 方向的一个平移 ——
**那正是 rescoring 规则**。

⇒ **TTT 唯一可能赢的原因，是 decoder 表达不出任意分数向量**，
因而只能用「逐位点的、结构相关的」方式去逼近这个方向。**优势来自表达受限，不来自目标函数。**
这条给出了 **D-1** 的判据：把 `Δs = s_θ − s_frozen` 对 `c·w` 回归，R² 接近 1 ⇒ TTT 无意义。

### 2.4 评测协议与门槛

**14 个 assay**、per-assay Spearman、未加权均值。

| 臂 | `c` / `λ` 怎么选 | ρ |
|---|---|---:|
| 预训练基线 | — | 0.3903 |
| rescoring，`max + exp(−d/5Å)` | LOAO | 0.4551 |
| rescoring，`max + exp(−d/5Å)` | **oracle** | **0.4689 ← E-1 的门槛** |
| rescoring，`sum + exp(−d/5Å)` | oracle | 0.4850 |
| rescoring，`sum + 1/(1+d/20)` | oracle | **0.5074 ← 该族上确界** |

🔴 **门槛不是一个数**：本阶段 `λ` 是逐 assay oracle 选的，所以对照的 `c` 也必须是 oracle；
而**特征必须两边相同** —— TTT 用哪个 `w(·)`，就比哪个 `w(·)` 的那一行。
（早先把 0.4850 写成「本阶段门槛」是错的，已更正。）

## 4. 结果

### 4.1 前置实验 ①：`w(·)` 的**聚合方式**比 `τ` 重要得多

| 聚合 + 形式 | oracle `c*` | LOAO 共享 `c` |
|---|---:|---:|
| `sum` + `exp(−d/5Å)` | 0.4850 | **0.4599** |
| `sum` + `exp(−d/3Å)` | 0.4737 | **0.4582** |
| `mean` + `exp(−d/8Å)` | 0.4823 | **0.4572** |
| `max` + `exp(−d/5Å)` ← 摸底/E-1 用的 | 0.4689 | 0.4551 |
| *置换距离的 null（同样 best-of，3 seed）* | *0.3917* | *0.3903* |

- **`τ` 几乎不重要**：前 5 名的 `τ` 从 3 Å 到 12 Å，差别 < 0.004。
- **聚合才重要**：`max`（只看最近的那个突变位点）→ `sum`（每个位点都记一笔），oracle **+0.0161**。
  增益**全部**来自 9 个多点突变 assay —— 5 个单点突变 assay 的天花板在两种聚合下**逐位精确相等**
  （k=1 时 `max` 与 `sum` 是同一个数）。
- **null 干净**：置换距离后 LOAO 增益恰好 **0.0000**（3 seed 全是）⇒ 63 选 1 没有过拟合。

> 🔴 **这是第二次「零 label、零 GPU」把门槛推高。** 摸底里的 `τ=5 Å` 本身没问题，**选错的是聚合**。

### 4.2 两个门都过了

| | |
|---|---|
| **G-B** | 缓存 encoder 的可微实现 vs 官方 `compute_fitness_multi_pdb.py`，**最大相对偏差 3.0e-7**（float32 累加量级）。含带 Kabat insertion code 的 4ZFG。 |
| **G-A** | 线性探针读冻结的 node embedding `h_V`：**within-assay AUC 0.890、LOAO 0.915**。信息在，且**跨复合物共享**（LOAO 比 within 还高，因为训练数据多 13 倍）。 |

**⇒ 「decoder-only 可能表达不出来」这条风险解除。**
但**连续距离的可迁移性明显弱于二值接触**（ρ 0.404 vs 0.483）—— TTT 要学的恰是梯度，值得记着。

### 4.3 E-1：目标函数**有操作窗口**，5/8 达到或越过 oracle 天花板

特征统一 `max + exp(−d/5Å)`，所以对照的是**同特征**的 0.4689 那一档。

| assay | zero-shot | **TTT (λ\*)** | oracle 天花板 | **TTT − 天花板** |
|---|---:|---:|---:|---:|
| `KRAS_RAF1-RBD_norfitness_6VJJ` | 0.4413 | **0.6736** (λ=0.3) | 0.6079 | **+0.0658** ⭐ |
| `CD19_FMC63_Fitness_7URV` | 0.6032 | **0.6367** (λ=0.03) | 0.6144 | **+0.0223** ⭐ |
| `GB1_IgG-Fc_fitness_1FCC` | 0.5005 | **0.5645** (λ=0.3) | 0.5444 | **+0.0201** ⭐ |
| `5A12_Ang2_fitness_4ZFG` | 0.1074 | **0.1126** (λ=10) | 0.1077 | **+0.0049** ✅ |
| `PSD95_CRIPT_1BE9` | 0.3672 | **0.5559** (λ=0.1) | 0.5567 | **-0.0008** ✅ |
| `HLA-A2_TAPBPR_meanscore_5WER` | 0.4116 | **0.4233** (λ=0.1) | 0.4307 | **-0.0074** ✅ |
| `PSD95_Tm2F_1BE9` | 0.1944 | **0.2408** (λ=0.3) | 0.2592 | **-0.0184** ❌ |
| `ACE2_SARS2-RBD_enrich_6M17` | 0.2759 | **0.3237** (λ=0.03) | 0.4429 | **-0.1192** ❌ |

**λ 曲线的两端都符合预期**：`λ→∞` 单调回到基线；`λ→0` 一侧 `GB1` 明确塌缩到 **−0.2010**
（比预训练还差 0.20），正是 §2.1 预言的退化 ⇒ **峰是真峰，不是网格截断。**

**⇒ §5 判读表里「单调回落 = 方案否证」这一支已被排除。**

### 4.4 D-1：增益**不是**「用 GPU 重做那条五行规则」

把学到的位移 `Δs` 对 `c·w` 回归（§2.3 预先写好的判据）：

| assay | 单标量 R² | 残差占位移 RMS | **超出它自己的标量** |
|---|---:|---:|---:|
| `KRAS_RAF1-RBD_norfitness_6VJJ` | 0.669 | 0.345 | **+0.0807** |
| `PSD95_CRIPT_1BE9` | 0.694 | 0.400 | **+0.0202** |
| `GB1_IgG-Fc_fitness_1FCC` | 0.620 | 0.319 | **+0.0201** |
| `ACE2_SARS2-RBD_enrich_6M17` | 0.461 | 0.023 | **+0.0101** |

**单标量只解释约 2/3**；`KRAS_RAF1-RBD` 越过天花板的 +0.0658，正对应它 **+0.0807** 的
「超出自身标量」部分。⇒ **与 §2.3 的预言一致：优势来自 decoder 表达受限。**

### 4.5 `λ*` 的分布：主体集中在一个数量级，两个外点都能解释

`λ*` ∈ {0.001, 0.03, 0.1, 0.3, 10}，**7/8 落在 `[0.03, 0.3]`** —— 「一个共享 λ」不是没指望。

两个外点：`5A12` 的 λ*=10，因为它的 headroom 只有 **+0.0003**（本来就没东西可赚，
最优策略就是别动模型）；`ACE2` 的 λ*≤0.001，因为它需要的位移最大（`c*=−1.95`）。

⚠️ 但 **`λ*` 与 `|c*|` 的 Spearman 只有 −0.296**（n=8，不显著）⇒
**`L_anchor` 除以 `var(s_frozen)` 这个归一化，没有真的把 λ 做成跨 assay 可比的量**，
而那正是它的设计目的。

## 5. 结论

### 5.1 已经能说的

1. **目标函数有操作窗口。** 两端都按预言的样子出现（`λ→∞` 回基线、`λ→0` 塌缩到比基线更差），
   中间有峰。**「与 WT-likelihood 同类失效」这个最可能的结局被排除了。**
2. **TTT 学到的东西有约 1/3 不是标量能表达的**，而赢天花板的那部分正来自它。
   这与「优势来自 decoder 表达受限」的预言一致。
3. **界面先验的价值又一次被便宜的方法吃掉一部分**：改一个聚合函数（零 label、零 GPU）
   就把对照臂从 0.4689 推到 0.4850，oracle 上确界 0.5074。

### 5.2 还不能说的

**不能说 complexTTT 成立。** 按 §3 预先写好的判读表，「有峰且越过门槛」**不等于**
「验证了 insight」—— 还要排除「增益来自 TTT 本身的扰动 / 正则效应」。
**E-3 是唯一能区分的实验，未出。**

### 5.3 边界（读上面任何数字时都要带着）

1. **8 / 14 个 assay，而且不是随机抽的**（先挑了小的和有代表性的）。
   ⚠️ **剩下 6 个里有 3 个 KRAS，恰好是 headroom 最大的那批**（+0.10 ~ +0.13），
   与目前赢最多的 `KRAS_RAF1-RBD` 同家族 ⇒ **现在报的任何均值都不是最终值。**
2. **`λ*` 逐 assay oracle 选**，所以对照的天花板也是 oracle —— 两边 label 用量相同，这点是对的。
3. **8-assay 均值仍低于天花板 −0.0044**，完全由 `ACE2` 一个拖的。
   ⚠️ 去掉它是 +0.0120，**但「去掉最差的再报均值」本身就是挑数据**，这里并列写出只是
   为了不让读者以为 −0.0044 是普遍情形。
4. **训练预算不可比**：同样 300 步，`GB1` 只看了 0.29 个 epoch，`PSD95` 看了 23.8 个。
   且 `l_div` 在小 λ 下 300 步**没收敛** ⇒ **`λ*` 应读作「300 步预算下的最优锚强度」。**
   （细节见 tracking §3。）
5. **GPU 非确定性实测 ≈ 3e-6**，远小于任何被引用的效应。

## 7. 深入优化模型设计（用户 2026-09-13 提出的方向 + 即时验证）

> 想法本身：pooling multi-site 只是一条轴；另一条是**把距离映射成与 DMS_score 更相关的特征**，
> 这样更适合做 regularization，**甚至可能解决 `corr()` 的方向约束问题**。

### 7.1 两条轴是**独立**的，杠杆来源不同

| | 是不是 `d` 的单调变换 | 后果 |
|---|---|---|
| **换形状** `f(d)` | **是** | `Spearman(f(d),·)` 恒定不变 ⇒ 改不动任何**秩层面**的量 |
| **换聚合** `AGG_i f(d_i)` | **否**（`sum` 不是任何单个 `d_i` 的函数） | 秩也会变 |

⇒ **换形状有杠杆，不是因为特征「更像真值」，而是因为加性 rescoring 与 Pearson 对形状敏感** ——
而那恰好就是我们用的两个东西。实测：在 pooling 完全失效的 5 个单点突变 assay 上，
7 种形状之间的 oracle 差距**中位 0.0285、最大 0.1180**，且**每个 assay 的最优形状不同**。

### 7.2 🔴 方向问题基本由特征决定，不是模型的病

| 特征 | `\|corr(w,y)\|` 中位 | **起点符号与真值一致** | rescoring LOAO |
|---|---:|---:|---:|
| `max` + `exp(−d/5Å)`（E-1 在用） | 0.263 | **9/14** | 0.4551 |
| `sum` + `exp(−d/5Å)` | 0.295 | 10/14 | **0.4599** |
| **`sum` + `exp(−d/20Å)`** | **0.349** | **13/14** | 0.4047 ← 61/63 名 |

4 个 KRAS / GB1 **全部被修好**：`corr(w,s_frozen)` 翻成负，而 `corr(w,y)` **不但没翻、还更强**
（`KRAS_RAF1-RBD` −0.359 → −0.444）。唯一例外 `hYAP65` 的真值方向本来就 ≈0。

**⇒ 起点 13/14 正确意味着 loss 只需「加强」而不需「掰方向」，
那正是方向不感知目标（`−pearson²`）能正确工作的前提。**
早先「方向不感知在这批数据上更危险」的结论**绑定在旧特征上，必须重测**（→ §6 的 F-3）。

### 7.3 真正的发现：两个角色要的不是同一个特征

`sum + exp(−d/20Å)` 做 **rescoring 排 61/63**，却是**最好的 regularizer**（两个指标都最好）。
⇒ **「最适合做加性平移的特征」≠「最适合做相关性正则的特征」。**
后续设计里这两处**可以、而且大概应该**用不同的 `w(·)`（→ §6 的 F-2）。

### 7.4 一条预先写下的风险

把「形状」变成可学的（单调样条 / 小 MLP on `d`）**会再加一个需要 label 才能选的旋钮** ——
与 `λ` / `c` 是同一类问题（摸底记录已给出否定结论：静态 WT 特征里没有 pLDDT 的类比）。
**除非同时给出 label-free 的选法，否则它只抬高 oracle 上界、不让方法更可部署。**
