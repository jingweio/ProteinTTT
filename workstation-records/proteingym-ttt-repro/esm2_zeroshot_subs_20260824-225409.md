# proteingym-ttt-repro — experiment record  (created 2026-08-24 22:54; status: PLANNED)

复现 **ProteinTTT (ICLR 2026) Table 2** 的 protein fitness prediction 结果：在 **ProteinGym v1.3
DMS substitutions zero-shot** 上，量化 test-time training 对 ESM2 的增益。

---

## 1. Goal / hypothesis

**要复现的具体数字**（paper Table 2，Avg. Spearman）：

| row | Avg. Spearman | Activity | Binding | Expression | OrganismalFitness | Stability |
|---|---|---|---|---|---|---|
| ESM2 (35M) | 0.3211 | 0.3137 | 0.2907 | 0.3435 | 0.2184 | 0.4392 |
| **ESM2 (35M) + ProteinTTT** | **0.3407 ± 0.00014** | 0.3407 | 0.2942 | 0.3550 | 0.2403 | 0.4733 |
| ESM2 (650M) | 0.4139 | 0.4254 | 0.3366 | 0.4151 | 0.3691 | 0.5233 |
| **ESM2 (650M) + ProteinTTT** | **0.4153 ± 0.00003** | 0.4323 | 0.3376 | 0.4168 | 0.3702 | 0.5195 |

**Hypothesis under test:** ProteinTTT 报告的增益 **+0.0196 (35M) / +0.0014 (650M)** 在独立实现的
harness 上可复现，且方向/量级与 paper 一致。

**⚠️ 开工前已确认的一件事（决定了整个实验设计）：**
paper 的两行 **baseline 不是作者重算的，而是直接取自 ProteinGym leaderboard**。
我用本 repo 内 `refs/DMS_substitutions_Spearman_DMS_level.csv`（ProteinGym 官方发布的 per-assay
Spearman）跑官方 aggregation，得到：

| | 我从官方 CSV 聚合 | paper Table 2 | Δ |
|---|---|---|---|
| ESM2 (35M) | 0.3208 | 0.3211 | −0.0003 |
| ESM2 (650M) | 0.4138 | 0.4139 | −0.0001 |
| SaProt (650M) | 0.4566 | 0.4569 | −0.0003 |
| ProSST (K=2048) | 0.5069 | 0.5068 | +0.0001 |

per-category 除 `OrganismalFitness` 外**逐位完全相同**（如 ESM2-650M：Activity 0.4254、
Binding 0.3366、Expression 0.4151、Stability 0.5233 全部对上）；OF 差 0.0008–0.0014，方向不一致
（ProSST 反而偏高），推测是 paper 用的 ProteinGym 版本与本地 v1.3 之间某个 OF assay 有更新。

**这个 0.0003–0.0014 的 benchmark-version 噪声底，和 ESM2-650M 声称的增益 +0.0014 同量级。**
⇒ 650M 这一行**在统计上不是一个可判定的复现目标**；35M 的 +0.0196 是它的 14×，才是真正
可证伪的目标。这直接决定了下面的优先级。

## 2. Design & decision points

### 2.1 三段式设计（S0 是硬 gate）

- **S0 — harness validation gate（无 TTT）。**
  用自己写的 `scripts/eval_proteingym.py --mode baseline` 从原始 assay CSV 重算 ESM2 的
  masked-marginals 分数，与 ProteinGym **发布的 per-assay Spearman 逐 assay 比对**。
  **通过条件：** 217 个 assay 全部 `|Δ| < 0.01`，且聚合后 Avg. Spearman 复现 0.3208 / 0.4138。
  **S0 不过就不跑 S1** —— 否则 TTT 的 delta 无法与 harness bug 区分。
- **S1 — TTT（5 seeds）。** `--mode ttt --seed 0..4`，每个 assay 跑 `model.ttt(seq)` 后重新打分。
- **S2 — 聚合。** `scripts/aggregate_proteingym.py` 实现 ProteinGym 官方口径，输出 Table-2 式表格
  + Table A4 的 MSA-depth 分层。

### 2.2 KEY DECISIONS（选了什么 + 为什么）

| 决策 | 选择 | 理由 |
|---|---|---|
| **复现哪几行** | ESM2 (35M) **主**，ESM2 (650M) **次** | 这两行是 repo 里**唯一 ship 了官方 TTT config** 的（`DEFAULT_ESM2_35M_TTT_CFG` / `DEFAULT_ESM2_650M_TTT_CFG`）。SaProt 需要 foldseek 3Di tokens、ProSST 需要自己的 structure tokenizer + AF2 structures、ProGen2-large 是 2.7B —— 都要额外一整套数据/依赖，不属于"复现这个 repo"的最小闭环。35M 增益最大（+0.0196）⇒ 最可证伪。 |
| **scoring 口径** | ProteinGym `masked-marginals` log-odds ratio（Eq. 6），`offset_idx=1`，`mutant_col="mutant"`，fp32，逐位置 mask，`L+2>1024` 时用 `get_optimal_window` | 逐行转写自 `ProteinGym/proteingym/baselines/esm/compute_fitness.py`。**唯一改动：把共享同一 window 的位置 batch 起来**（数学等价，纯速度）。等价性不靠断言，靠 S0 实测。 |
| **metric 实现** | 聚合用 `scipy.stats.spearmanr`（与 ProteinGym 一致）；eval 脚本里 `pandas.corr` 只用于进度日志 | 权威数字只能来自官方口径的那条路径。 |
| **aggregation** | per-assay ρ → `groupby(UniProt_ID, coarse_selection_type).mean()` → `groupby(coarse_selection_type).mean()` → 5 类取均值 | ProteinGym README 明确说 **不是 217 个 assay 的算术平均**，要校正每个蛋白的 assay 数与 function group。已用官方 CSV 验证这条路径能复现 leaderboard 数字（§1 表）。 |
| **seed 语义** | `ttt_generator.manual_seed(seed*1000003 + crc32(DMS_id))`，每个 (seed, assay) 独立 | paper 只说 "5 random seeds"。派生式 seeding 让**单个 assay 可以单独重跑并 bit-for-bit 复现**，同时避免等长 assay 之间 mask 相关。 |
| **每个 assay 都重算 pre-TTT 分数** | 是（`score_pre_ttt` 列在 ttt 模式下也写） | 额外 ~15% 开销，换来一个免费的正确性 guard：5 个 seed 的 `score_pre_ttt` 必须**完全一致**，否则说明 `ttt_reset()` 没有真正复原权重（base.py 的 `_ttt_get_state` 只遍历 `named_children()`，是个真实的风险点）。 |
| **TTT 超参** | 一律用 repo 里 ship 的 config，不调 | 复现 ≠ 调参。35M: `lr=4e-4, batch_size=4, ags=16, steps=30`；650M: `lr=4e-5, batch_size=4, ags=4, steps=30`；两者 `loss_kind=unnormalized_cross_entropy, optimizer=sgd(momentum=0), mask_ratio=0.15, crop_size=1024`。与 paper Table A3 / Figure A9 一致。 |
| **confidence function** | 不启用（`score_seq_kind=None`, `_ttt_eval_step` 用基类默认） | Table A3 的 fitness 行 "Steps (Conf. func. c)" 只写 30，没有括号里的 conf func —— fitness 任务固定跑满 30 步、取末步权重。代码路径上 `confidence=None` ⇒ `best_state` 不触发。 |

### 2.3 数据与规模（实测，非估计）

- ProteinGym **v1.3**，`DMS_ProteinGym_substitutions.zip`
  sha256 `3a83766254ac9ac9984ec25cb73c6e010ea4418f5e35f143933e6b6e6473b921`（与官方 manifest 一致）。
- **217 assays / 186 unique UniProt / 187 unique target_seq / 2,465,767 variants。**
- phenotype: OrganismalFitness 77、Stability 66、Activity 43、Expression 18、Binding 13。
- MSA depth: Medium 109、High 72、Low 36。
- seq_len: min 37 / median 245 / p75 536 / max 3423；**16 个 assay 超过 1024**（走 optimal-window）。
- 一次完整 scoring sweep = **86,613 次 masked forward pass**（Σ(L+2)）。
- TTT per assay：35M = 30×16 = **480 个 micro-batch**（bs=4）；650M = 30×4 = **120 个 micro-batch**。
  全量 217×5 seeds：35M = 520,800 micro-batch；650M = 130,200 micro-batch。
