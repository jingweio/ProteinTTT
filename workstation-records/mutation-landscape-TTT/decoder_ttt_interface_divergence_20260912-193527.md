## 1. 立题

### 1.1 要做什么

**transductive、decoder-only 的 test-time training**：

- **transductive**：模型**看得到该 assay 的 mutant 序列**，但**看不到它们的 DMS label**；
- **只微调 decoder**，**冻结 encoder**（假定 structure encoder 已经学得足够好）；
- **训练信号**：让模型对 `mutants_{碰 binding-site}` 与 `mutants_{不碰}` 的**预测分数分布差异变大**。

### 1.2 待检验的假设

**假设**：预训练 ProteinMPNN 的 decoder 没有把「突变位点离 partner 多近」这件事用起来
（摸底记录 §1.3 已证实）；在 test time 用一个**不需要 label** 的目标把它逼出来，排序能力会提升。

### 1.3 这个实验能回答什么、不能回答什么

| | |
|---|---|
| **能回答** | 「把界面先验**训进 decoder**」是否比「**事后加一个平移**」更好 |
| **不能回答** | 界面先验本身值多少钱 —— 那已经由摸底记录回答了（LOAO **+0.0648**） |

**⇒ 本实验的对照臂是 rescoring 规则，不是预训练基线 0.3903。**
而**具体拿哪个数当门槛，取决于 `λ` 怎么选** —— 本阶段逐 assay 扫 `λ`（oracle），
所以门槛是 **oracle `c*` 的 0.4689**；等做了 LOAO 版本，门槛才是 **0.4551**。见 §2.1。

## 2. 🔴 一个必须先处理的结构性问题：目标函数的最优解是退化的

「最大化两组分数分布的差异」如果**不加约束**，它的全局最优是：
把所有碰界面的 variant 推到 −∞、不碰的推到 +∞ —— 也就是**让分数变成界面特征的一个函数**，
**组内的全部信息被丢光**。那时 Spearman 等于「用界面特征单独当预测器」：

| 分数塌缩成 | 14-assay Spearman |
|---|---:|
| 预训练基线 | **0.3903** |
| 纯二值界面标签 | **0.2068**（低 0.1836） |
| 纯连续距离特征 `exp(−d/5Å)` | **0.2564**（低 0.1339） |
| rescoring 规则（本实验的门槛） | **0.4551** |

**⇒ 无约束版本的最优解比起点还差 0.13–0.18。**
这与既往**已被否证**的 WT-likelihood TTT 目标是**同一类失效** —— 目标函数的最优解不是我们想要的东西。

### 2.1 所以目标必须写成「散度 + 锚」

```
L(θ) = − Divergence( 模型分数 , 界面先验 )  +  λ · Anchor( s_θ , s_frozen )
```

- `λ → ∞` ⇒ 回到预训练模型；`λ → 0` ⇒ 塌缩到 0.2564。**中间是否存在一个峰，就是本实验要测的东西。**
- 🔴 **`λ` 就是摸底记录里那个 `c` 的化身** —— 它控制「往界面方向推多远」。

**`λ` 怎么定（用户 2026-09-12 决定）**：**本阶段不做跨 assay 选参**。
`λ` 当作 TTT 模型的一个**超参**，**在当前 assay 上直接扫一组值**，看哪个区间稳定。

> 🔴 **这个决定的直接后果，必须写在结果里**：逐 assay 扫 `λ` 并报最好的那个，
> 用到了**该 assay 的 label** ⇒ 它是一个 **oracle 选择**。
> **因此公平的对照臂变成 oracle 逐 assay `c*` 的 `0.4689`，不是 LOAO 的 `0.4551`。**
> 拿 oracle-λ 的 TTT 去比 LOAO 的 rescoring，是拿 oracle 比非 oracle，不算数。
>
> 这在**摸底阶段是允许的**（探针可以用 oracle、可以不可实现）。
> 等探针出结果、确实存在可用区间之后，再做 LOAO 版本，那时门槛才回到 0.4551。

**扫 `λ` 还顺带回答另一个问题**：把每个 assay 的 `λ–ρ` 曲线画出来，
看**各自的平台区间有没有交集** —— 有交集就说明「一个共享 `λ`」可行，方法才有部署的可能。
（同一套判据在摸底记录里用过：`c*` 的平台中位宽 0.20 sd-units，KRAS 四个 assay 的平台交集非空。）

## 3. 实验框架

### 3.1 变量定义

| 符号 | 定义 | 训练时可见吗 |
|---|---|---|
| `s_θ(v)` | 微调后 decoder 给 variant `v` 的分数（与预训练同一个打分口径） | — |
| `s_frozen(v)` | 冻结模型给的分数 | ✅ |
| `d(v)` | `v` 的突变位点到**另一个 entity** 的最小重原子距离（WT 复合物算出） | ✅ **label-free** |
| `w(v)` | 界面先验权重，由 `d` 映射而来，**取值 0–1**，见 §3.2 | ✅ label-free |
| `y(v)` | 真实 DMS_score | ❌ **训练时绝不可见**，只在评测时用 |
| `λ` | 锚的强度；LOAO 选 | — |

### 3.2 从 binary 到 soft：三种散度写法（你问的那一点）

摸底记录 §5.1 已经证明：**界面效应是一条关于距离的平滑梯度，不是 5 Å 处的阈值**
（5 Å 两侧各自内部的趋势都显著）。所以**二值写法先天丢信息**，其 oracle 上界也更低（0.4402 vs 0.4689）。

| 写法 | Divergence 怎么算 | 判断 |
|---|---|---|
| **(a) 二值两组** | 两组分数经验分布的 Wasserstein / 标准化均值差 | 你最初的提法。**不推荐做主方案** —— 与已测到的梯度不符，上界更低 |
| **(b) 连续加权（推荐）** | `Div = − corr( w(v), s_θ(v) )`，`w = exp(−d/τ)` | **一个可微标量，直接对应已测到的梯度**；超参只有 `τ` |
| **(c) 分档序数** | K 档之间的 pairwise ranking loss（越近的档分数越低） | (b) 的稳健性变体；K、档边界是额外超参 |

**主方案 = (b)，(c) 作为稳健性检查，(a) 只作为消融**（用来验证「连续确实优于二值」在 TTT 下同样成立）。

### 3.3 评测协议

沿用摸底记录：**14 个 assay**、per-assay Spearman、未加权均值。

| 臂 | 是什么 | 期望 |
|---|---|---|
| 预训练基线 | 不动模型 | 0.3903 |
| rescoring，`c` 由 LOAO 选 | `s + c·sd·exp(−d/5Å)` | 0.4551 |
| **rescoring，`c` 逐 assay oracle** | 同上，`c*` 用该 assay 的 label 选 | **0.4689 ← 本阶段门槛** |
| **TTT（本阶段）** | **`λ` 逐 assay 扫** —— 同样是 oracle 选择 | **必须 > 0.4689** |
| *TTT（后续 LOAO 版）* | *`λ` 在其余 13 个 assay 上选* | *那时门槛才回到 0.4551* |

> **门槛为什么是 0.4689 而不是 0.4551**：两条臂必须**用掉同样多的 label 知识**才可比。
> 本阶段的 `λ` 是在当前 assay 上扫出来的（oracle），所以对照的 `c` 也必须是 oracle `c*`。
> 拿 oracle-λ 的 TTT 去比 LOAO 的 rescoring，是**拿 oracle 比非 oracle**，不算数。

### 3.4 主方案 (b) 的实现细节

#### (i) 被优化的分数 `s_θ(v)` —— 必须与评测用的是同一个函数

`s_θ(v)` = **官方 BindingGYM 打分口径**：把 variant 的突变序列做 autoregressive teacher-forced，
在 mask 上**求和** NLL 取负（**无 WT 项、无长度归一化**），对 M 个解码顺序取均值。
它对 decoder 参数**可微**，可以直接当 loss 的一部分。

🔴 **训练用的打分函数与评测用的必须逐行相同**，否则优化的是一个东西、评测的是另一个。
实现上只允许有一处差别：**训练 M=1**（每步重抽一个解码顺序，等于给梯度加噪），
**评测 M=5**（与基线同口径）。这一条在 G-B 里用 assert 钉住。

#### (ii) 冻结 encoder 带来的关键优化：encoder 只跑一次

结构是**固定的 WT 复合物**，而 encoder 被冻结 ⇒ **node/edge embedding 对该 assay 的所有 variant 完全相同**。
所以：**每个 assay 只跑一次 encoder，把 `h` 缓存下来；训练时只跑 decoder。**
这不是优化技巧，是 decoder-only 设定的直接推论 —— 它把单步成本降到只有 decoder 的量级。

#### (iii) Loss

对一个 minibatch `B`（变体集合的一个子集）：

```
w̃  = standardize( w(v) ),    w(v) = exp( −d(v) / τ )        # 界面先验，label-free
s̃  = standardize( s_θ(v) )                                   # batch 内标准化
L_div    = + pearson( w̃ , s̃ )          # 最小化它 ⇒ 把 corr 推向负，即「越近分越低」
L_anchor = mean( ( s_θ(v) − s_frozen(v) )² ) / var( s_frozen )   # 除以方差，使 λ 跨 assay 可比
L        = L_div + λ · L_anchor
```

- **为什么是 Pearson 而不是 Spearman**：Spearman 不可微。这里**优化 Pearson、评测 Spearman**，
  是一个**代理间隙**，必须在结果里如实写明。
- **`L_div` 写成 `+pearson`（而不是 `−|pearson|` 或 `−pearson²`）是一个有方向的假设** ——
  见 §3.4(iv) 末尾：更一般的「方向不感知」版本是**后续方向**，但在这批数据上先不用，原因已量化。
- **为什么 batch 内标准化**：让 `L_div` 与分数的绝对尺度无关（与 rescoring 里 `sd(score)` 同一个道理）。
- **`L_anchor` 除以 `var(s_frozen)`**：否则 λ 在不同 assay 上的实际强度不同、LOAO 选出来的 λ 不可迁移。

#### (iv) 这个 loss 的起点与终点 —— 在训练之前就能量化

主方案的 `L_div` 只是一根**一维的轴**：`corr(w, 分数)`。
模型现在落在这根轴的某处，真值落在另一处，**loss 要做的就是把它从前者推到后者**。
两端都能从已有数据直接算出来（脚本 `t1_loss_axis.py`，14 assay，`τ = 5 Å`）：

> 「符号翻转」的那批（3 个 KRAS + GB1 + hYAP65）。对它们来说这个 loss 不是「加强一个弱信号」，
> 而是**把方向掰回来**，所以移动幅度最大（−0.50 ~ −0.02）。

**三条设计含义：**

1. **目标方向是明确的且几乎普适**（13/14 一致）⇒ `L_div` 的符号不需要逐 assay 判断，写死即可。
2. **要移动的幅度不大**（中位 0.19 的相关系数）⇒ **不需要大 lr、不需要长时间训练**；
   这与「lr ≥ 1e-2 会摧毁排序」的既往实测一致，支持从 **1e-4** 起步。
3. **`corr(w, y)` 就是这根轴上的天然目标值** ⇒ 除了扫 `λ`，还有一个**更受约束的变体**可试：
   直接把 `corr(w, s_θ)` 拉向**该 assay 的 `corr(w, y)`**。
   ⚠️ 但 `corr(w, y)` **用到了 label**，所以它只能作为 **oracle 上界参考**，不能当方法 ——
   除非能用 label-free 的方式估它（与 `λ` / `c` 是同一个未解决问题）。

##### 方向性：正确的假设是「存在强相关」，不是「相关为负」（用户 2026-09-12）

**用户的意见是对的**：`corr(w, y) < 0` 在 14/14 上成立只是这批数据的**观测**，
不该被当成方法的**强假设**。更一般的目标应当是**方向不感知**的 —— 只要求
`|corr(w, s_θ)|` 变大（如 `L_div = −pearson²`），让数据自己决定符号。

**但在这批数据上，方向不感知会更难，而且原因是可量化的：**

| | |
|---|---:|
| `sign(corr(w, s_frozen)) ≠ sign(corr(w, y))` 的 assay | **5 / 14** |
| 其中「模型当前为正、真值为负」 | **4 / 5** 个当前为正的 |
| 这 5 个需要移动的幅度 \|gap\| 中位 | **0.393** |
| 其余 9 个 | **0.132** |

⚠️ **方向不感知会放大模型当前的符号** ⇒ 它会把这 5 个推向**错误方向**，
而它们恰恰是**最需要修的那一批**（要移动的幅度是其余的 **3 倍**，含 3 个 KRAS + GB1）。

**还有一个技术问题**：`−pearson²` 在 `corr = 0` 处**梯度为零**（那是一个驻点），
而模型的起点中位正好是 **−0.021**，几乎就在那里。**任何「最大化依赖性」的目标在独立点都是驻点**，
这不是选哪个散度能绕开的。

**所以本阶段的决定**：
- **先用有方向的版本**（`L_div = +pearson`）。方向来自**生物物理先验**（突变界面残基损害结合），
  这是 **label-free 的**，不是从测试 assay 的 label 里读出来的 —— 所以用它**不算作弊**。
- **方向不感知列为后续方向**，它真正缺的是：**一个 label-free 的定符号方式**。
  这与 `λ` / `c` 的选择是同一类问题（见摸底记录 §4.2 的否定结论）。

#### (v) 🔴 一个必须预先说明的理论点：L2 锚会让最优解**退化回 rescoring 规则**

若把 `s` 当作**不受网络限制的自由变量**，`L_div + λ·L2` 的最优解就是
**沿 `w` 方向的一个平移** —— 也就是 `s = s_frozen − c·w`，`c ∝ 1/λ`。**那正是 rescoring 规则。**

⇒ **TTT 唯一可能赢过 rescoring 的原因，是 decoder 表达不出任意分数向量** ——
它被网络结构约束住，因而只能用「逐位点的、结构相关的」方式去逼近这个方向。
**优势来自表达受限，不来自目标函数本身。**

**由此得到一个必做的诊断（便宜）**：把实际学到的 `Δs = s_θ − s_frozen` 与 `c·w` 做回归。
- **近似成比例**（R² 高）⇒ TTT **只是学会了那个标量**，没有额外信息；
- **有明显残差，且残差与性能提升相关** ⇒ decoder 学到了标量表达不了的东西（**这才是我们要的**）。

#### (vi) 可训练参数

冻结：encoder 全部 + embedding。可训练：**decoder 的 3 层 `DecLayer` + 输出投影 `W_out`**。
消融：**只训 `W_out`**（最小干预）。
> 参数量在 G-B 时实测记录（ProteinMPNN 总共 ~1.7 M，decoder 只占一部分），不预先猜。

#### (vii) minibatch 怎么取 —— 容易错的一点

`L_div` 是 batch 内的相关系数，**如果一个 batch 里 `w` 几乎没有方差，这一项就没有梯度**。
⇒ **必须按 `d` 的分位数做分层采样**：每个 batch 从 5 个距离档里等量抽。
batch size 先取 **128**（每档 ~26），太小则 Pearson 估计噪声过大。

#### (viii) 优化与停步

| 项 | 取值 | 理由 |
|---|---|---|
| optimizer | Adam | — |
| **lr** | **1e-4 起**（并扫 3e-5 / 3e-4） | 既往实测：**lr ≥ 1e-2 会直接摧毁排序能力**（0.705 → 0.388），不要从大 lr 开始 |
| **停步** | **训到收敛，不做 early stopping** | **`λ` 是唯一的旋钮**。若同时用步数控制「推多远」，λ 与步数会互相混淆，曲线无法解释 |
| seed | ≥3 | TTT 会叠加方差 |
| 每个 assay | **独立训一个模型** | 不允许跨 assay 泄漏 |
| **`λ`** | **在当前 assay 上扫一组值**（本阶段），建议对数网格 ~6–8 个点 | 本阶段是**摸底**，目的是找出「有没有稳定区间」；对照臂因此是 **oracle `c*` = 0.4689**（见 §2.1） |

#### (ix) 与「实验 ①（特征调优）」的依赖关系

`τ` 现在是 **5 Å**，而它是从二值 cutoff 继承来的、**从未优化过**（见摸底记录 §6.2）。
**实验 ① 会直接给出更好的 `τ` 与多点突变的聚合方式。**
⇒ **建议实验 ① 先跑**（CPU ~30 min），让本实验从一个调好的 `w(·)` 出发；
否则 TTT 会在一个次优的先验上做，结果不好也分不清是「TTT 没用」还是「先验没调好」。

## 4. 实验网格与递进链条

**一次只动一个因素；能在前面杀掉就别往后走。**

| 步 | 问什么 | 为什么是现在 | 代价 | 杀掉它的结果 |
|---|---|---|---|---|
| **G-A** | **冻结的 encoder 到底区不区分界面位点？** 在冻结的 node embedding 上训一个线性分类器预测界面标签 | decoder-only 成立的**前提**：若 `h` 里没有界面信息，decoder 再怎么调也表达不出来 | **~15 min GPU** | AUC 接近随机 ⇒ **必须解冻 encoder，或换方案** |
| **G-B** | **no-op 对照**：`steps=0` 的 TTT 能否**逐 md5 复现**预训练分数 | 不能复现就说明 harness 本身有问题，后面全部结果不可信 | ~10 min | 不复现 ⇒ 先修 harness |
| **E-1** | **`λ` 扫描**（主方案 (b)）：曲线是单调回落到 0.2564，还是中间有峰？ | §2 说明这条曲线的两端已知，**只有中间未知** | **~1 GPU-h**（4 个代表性 assay × M=1） | 无峰 / 峰 < 基线 ⇒ **方案否证，停** |
| **E-2** | 最优 `λ` 附近在**全部 14 assay × M=5** 上评 | E-1 若有峰才做 | ~3 GPU-h | ρ < 0.4551 ⇒ 没赢过五行规则 |
| **E-3** | **随机置换 null**：把 `d` 在 assay 内随机置换后跑同一套 TTT | 不做这个，无法区分「学到了界面」和「TTT 本身带来的任何扰动」 | ~1.5 GPU-h | null 也涨 ⇒ **增益不来自界面** |
| **E-4** | 消融：(a) 二值 vs (b) 连续 vs (c) 分档；以及「只训 `W_out`」 | 验证「连续优于二值」在 TTT 下是否同样成立 | ~2 GPU-h | — |
| **D-1** | **诊断（CPU，免费）**：把学到的 `Δs = s_θ − s_frozen` 对 `c·w` 做回归 | §3.4(v)：若 `Δs ∝ w`，说明 TTT 只是学会了那个标量 | ~0 | R² 接近 1 ⇒ **没有额外信息，TTT 无意义** |

**合计上限 ≈ 8 GPU-h**，但 **G-A / E-1 就能杀掉方案**，实际可能只花 1.5 GPU-h。

> **前置建议**：先跑摸底记录 §6.2 的**实验 ①（特征调优，CPU ~30 min）**，把 `τ` 与多点突变的聚合方式调好，
> 本实验再从调好的 `w(·)` 出发 —— 否则结果不好时分不清是「TTT 没用」还是「先验没调好」。见 §3.4(ix)。

## 5. 预期结果与判读（**先写下来，再跑**）

| `λ` 扫描曲线的形状 | 结论 |
|---|---|
| **单调回落**（λ 越小越差，一路走向 0.2564） | 目标函数**没有操作窗口** —— 与 WT-likelihood 那次同样的失效。**方案否证。** |

| **有峰、> 0.4551、且 null 不涨** | ✅ **真结果** —— decoder 学到了标量表达不了的东西（大概率是**逐位点的权重**：不是所有界面残基都同等重要）。 |

## 6. 已知风险

1. **`λ` 的选择继承了同一个未解决问题**（§2.1）。LOAO 让它可比、但不让它「zero-shot」。
   摸底记录 §4.2 已证明：**静态 WT 特征里没有 pLDDT 的类比**。
2. **transductive 到底加了什么**：界面标签本身从 WT 结构就能算，**不需要看 mutant 序列**。
   所以 transductive 唯一多给的是**变体集合的经验分布**（用来算 Divergence）。
   ⇒ 若最终方案只用到 `w(v)`，那它其实**是 inductive 的**，应当如实说明。
3. **decoder-only 可能表达不出来** —— 这正是 G-A 要测的。
4. **每个 assay 一个模型** ⇒ 14 个 TTT 模型，seed 方差会叠加。至少 3 个 seed。
