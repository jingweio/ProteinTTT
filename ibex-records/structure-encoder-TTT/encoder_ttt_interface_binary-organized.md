## 1. 问题与 hypothesis

给定某个 assay 的 **WT complex structure**，在 test time **只用结构本身（零 DMS label）**
调整 ProteinMPNN 的 **encoder**，提升它在 BindingGYM 上的 zero-shot 表现。

**H**：把 `h_V` 中「界面 / 非界面」的可分性训上去，**同时约束分数不要离预训练太远**，
per-assay Spearman 会变好。

**效果门槛（用户定死）**：**只要优于预训练 zero-shot 即可** —— 14-assay **0.3903**。
本条线的定位是**学一个更好的基础表征**给下游 mutation-landscape-TTT 用，
**不要求**去比 rescoring 那一族更强的后处理（那边门槛 0.4689 / 0.4551，与此处无关）。

**起点事实**（来自 `structure_ttt_encoder-proposal.md`，非本次产出）：
冻结 encoder 的 `h_V` 上训线性探针，界面信息**线性可读但只读出一半** ——
`AP_norm,within` 均值 **0.484**（AUC 0.842）。**优化空间在 AP_norm，不在 AUC。**

## 2. 系统

```
WT complex X ──[encoder E_θ]──→ h_V ──┬─→ [probe head g_ψ] ──→ 界面 logits   ← 散度项（零 DMS label）
                                      │
                                      └─→ [decoder D_φ，全程冻结] ──→ s_θ(v)  ← 锚项 ＆ 评测
                                                                        │
                                                per-assay Spearman → 14-assay 未加权平均 = ρ
```

### 2.1 目标函数

```
L(θ,ψ) = L_probe                                        +   λ · ‖ s_θ − s_frozen ‖² / var(s_frozen)
         └── 散度：把界面在 h_V 里分开               └── 锚：不许最终分数离预训练太远

L_probe = −(1/L') Σ_r [ w_pos·y_r·log p_r + (1−y_r)·log(1−p_r) ]    p_r = σ(g_ψ(h_V,r))
          w_pos = (1−π)/π                                          ← 类别不平衡校正，逐 assay 算
```

**锚作用在 `s_θ` 而不是 `h_V`**（2026-09-15 改）：我们真正在乎的是分数的排序，表征只是手段；
Frobenius 罚项约束的是「表征移动了多远」，而不是「这个移动有没有抵达 decoder」，是一个糟糕的代理。
形式取自 decoder 侧已验证有效的目标（`transduc_decoder_ttt_interface_divergence-organized.md` §2.2）。
`var(s_frozen)` 取**该 assay 全部 variant** 的方差 —— MPNN 的 NLL 求和跨 assay 尺度差 **3.3×**，
不归一化则 λ 不可跨 assay 比较。

**计算结构的后果**：锚需要 `s_θ`，所以**每个训练步都要跑 decoder**并把梯度回传进 encoder。
旧方案只跑 encoder。这是本次改动里最贵的一项。

### 2.2 变量与可见性

| 符号 | 定义 | **训练时可见吗** |
|---|---|---|
| `h_V` | encoder 的 node 输出，每残基 128 维；`L` = 打包后的残基槽位数（56–1107） | — |
| `y_r` | `1[d(r) ≤ 5.0 Å]`，`d(r)` = 残基 `r` 的重原子到**另一个 entity** 全部重原子的最小距离 | ✅ 由**结构 + 元数据 entity 划分**算出，**不含任何 DMS label** |
| `π` | 该 assay 的界面残基比例（0.038–0.339，均值 0.126） | ✅ 同上 |
| `s_θ(v)` / `s_frozen(v)` | 微调后 / 冻结的分数，**与评测用的是同一个函数**（官方 BindingGYM 口径） | ✅ 只用 variant 的**序列**，transductive，绝不碰 `DMS_score` |
| `λ` | 锚强度 | — |
| `θ` / `ψ` / `φ` | encoder / probe head / **decoder（🔒 全程冻结）** | — |
| `ρ` | per-assay Spearman → 14 assay 未加权平均 | ❌ **只在评测用** |

> 🔴 **`y_r` 对 DMS 而言是 label-free 的** —— 界面标签来自结构，把它当 test-time 监督信号不构成泄漏。
> 分数锚也只用 variant 序列，不用 `DMS_score`。这是整条线成立的前提。

**`w_pos` 的量级**：π 从 0.038（`KRAS_PICK3CG-RBD`）到 0.339（`hYAP65`）⇒ `w_pos` 从 **25.3** 到 **1.95**，
跨 assay 差 **13 倍**，必须逐 assay 算。界面是少数类，不加权则梯度被多数类主导，
**AUC 好看而 AP_norm 不动** —— 而优化空间恰在 AP_norm。

## 4. 判据

1. **T0（已过）**：`--steps 0` 时分数与 baseline **逐行相同**。
   实测 **`max|Δscore| = 0.000e+00`**；且 baseline ρ 与换平台前记录值 **max|d| = 0.0020**
   （`CD19` 逐位相同，另两个 +0.0019 / +0.0005，远在 per-assay seed σ 中位 0.0184 之内）。
   ⚠️ 换平台后**不是逐位可复现**，只是噪声内一致 —— 不可声称 bit-identical。
2. **`step 0` 的锚必须恒等于 0**：`s_θ ≡ s_frozen` 时 `L_anchor = 0`。
   🔴 这条是**实测加上的**：首版实现里它是 **0.845**，因为 `s_frozen` 是 M=5 个解码顺序的平均、
   而训练每步只采一个顺序 —— 锚在惩罚「单序 vs 多序平均」，模型于是去学「模仿 M 平均」。修法见 §5.2。
3. **M1 的成败**：`ρ_M1 > 0.3903`（14-assay）。两臂必须共用同一组解码顺序（同一 `randn`），
   否则读不出 <0.02 的效应（配对下 gain 的 sd 只有 0.0037，单臂 σ 中位 0.0184）。
4. **M2 必须显著低于 M1**：若置换 null 也涨到同一量级，增益**不来自界面先验**。
   报告写成**定量占比**（null 增益 / 真实增益），不写成是非题。
5. **`AP_norm` 只作监控，不作证据**：TTT 后在新 `h_V` 上重训独立探针。
   ⚠️ **它证明不了泛化** —— encoder 在全部残基上训过，标签信息已进 `h_V`，
   探针的 5-fold 留出的是 `h_V` 的行、不是标签，**检测不到 encoder 层面的记忆**。

## 5. 会静默出错的地方

### 5.1 索引与过滤
- 🔴 **`parse_PDB` 把晶体学缺口补成坐标 (0,0,0) 的假残基**，`mask` 置 0 但**在 `h_V` 里占着行**。
  实测最高 **17.3%**（`KRAS_PICK3CG`）。`L_probe`、`π`、`w_pos` **都必须按 `mask` ＋「是否填充位」过滤**。
- `h_V` 的行序 = `tied_featurize` 的打包顺序（**designed chains 在前**，每链按 PDB 残基顺序）。
  标签直接在 PDB 空间算，**不需要 WT 序列对齐**。

### 5.2 锚必须与被锚的量同口径（实测教训）
- 🔴 **锚要对同一个解码顺序**。评测分数是 M=5 个顺序的平均，训练每步采一个顺序；
  拿单序去锚 M 平均，`step 0` 的锚就是 **0.845** 而非 0，整个训练被「模仿 M 平均」主导。
  修法：预先算 **(M, N) 的逐顺序冻结分数**，每步用**对应那一行**。修完实测 `step 0` 锚 = **3.48e-11**。
- **`var(s_frozen)` 取全 assay 的方差**（评测口径那个量），不用 batch 内方差 —— 否则 λ 随 batch 抖。

### 5.3 缓存与配对
- 🔴 **TTT 后必须重建整个 encoder cache，不能只 `set_h_V()`**。
  `AssayContext` 把 encoder 输出缓存为 `h_V` **和 `h_E`**，并由二者构造 `h_EXV_encoder` / `h_EXV_fw`；
  `set_h_V()` 只重建依赖 `h_V` 的那一半。**重训 encoder 后两者都变**，只调它会静默沿用旧的 `h_E`。
  ⇒ 用新权重、**同一个 `randn`** 重新构造 `AssayContext`。
  （同理，训练中的可微打分也必须从当前 `h_V`/`h_E` 重建这些派生量，不能读缓存。）
- **两臂共用解码顺序**：`AssayContext.__init__(..., randn=)` 显式传入。
  这同时绕开「`model.train()` 触发 dropout → 推走 CUDA RNG → 两臂 randn 不同」那个坑
  ⇒ 训练全程保持 `model.eval()`。
- **口径**：本文档所有数字一律 **14 assay，基线 0.3903**，不与 23/25 口径并列。

## 6. 还不能说的 / 下一步（按「能改变结论的程度」排）

**现在还不能说的**：
- H 尚未被任何有效的干预性证据检验。proposal §3 那条 `AP_norm,within` vs `ρ_zeroshot`
  的相关（Spearman **+0.515, p=0.060**, n=14）**未达显著**，且自列 3 个混淆项。
- **上一版（表征锚）的实验不构成对 H 的检验** —— 见 tracking「已作废方案」：
  encoder 在全部残基上训、907 K 参数对 56–1107 个残基，**记住标签是平凡的**，
  而那一版的诊断手段区分不了「学到几何」与「记住标签」。

**下一步**：
1. **soft-label 回归版**（用户 2026-09-15 定的后备方案）：若本版效果仍不好，
   把 `L_probe` 的二分类换成对 **`w(r) = exp(−d(r)/5Å)`** 的回归。
   理由：二值标签只说「碰不碰」，而 `w` 保留「多近」——
   且 `d` 的连续形式在 23/23 个 assay 上都有变化，二值标签只在 14 个上可评。
2. **参数量与样本量的匹配**：`encoder_layers + W_e` = **907,776** 可训练参数 vs `L` = 56–1107 个残基
   （`PSD95_CRIPT` 是 **7,500 : 1**）。若出现记忆迹象，应大幅收缩可训练集合
   （如只训 LayerNorm 的 scale/bias，全网约 **7 K**，少 130 倍）。
3. **λ 的 label-free 选法** —— 这是两条 TTT 线共同的瓶颈；本任务因门槛低而暂时回避（固定 λ），
   要落地必须解决。已知：训练目标自身单调无峰（已排除）；下一个候选是 ESM2 ensemble agreement。

## 附录 A：超参的选择与理由

| 项 | 取值 | 理由 |
|---|---|---|
| **可训练参数** | **`encoder_layers` + `W_e`** = 907,776（54.7%），`features` 冻结 | 实测 total 1,660,485；decoder 侧 695,445（41.9%，与 decoder-TTT 记录逐位吻合 ⇒ 交叉验证通过）。**`features` 是坐标→RBF 的几何入口**，改它等于改结构表示的基底；界面编码由做消息传递的 `encoder_layers` 决定。`--train_features` 作为开关，默认关 |
| optimizer | **AdamW**，`weight_decay=0` | 短训；正则由锚显式承担，不要两套正则互相干扰 |
| lr | E-2 扫 **{3e-5, 1e-4, 3e-4}** | decoder-TTT 那侧只验证过 1e-4。encoder 更靠近输入、扰动传播更远，**先验上应更保守**，故纳入 3e-5 |
| steps | E-2 扫 **{50, 150, 400}** | 扫的是「什么时候开始坏」，不是「多久收敛」 |
| λ | E-1 扫 **{0.1, 1, 10, 100}** | 量级未知。⚠️ 锚已换成分数层面，**旧方案的 λ 量级不可迁移** |
| `anchor_batch` | 32 | 每步用于分数锚的 variant 数；太小则锚的估计噪声大 |
| `anchor_M` | 1 | 每步采一个解码顺序（省 M 倍），并与 §5.2 的逐顺序参照配对 |
| 打分 batch | 64 | decoder-TTT 实测：14 assay 统一 batch 的上限是 64，被 `KRAS_PICK3CG`(L=1107) 卡住 |
| 精度 | **fp32** | 模型仅 ~1.7 M 参数；避免混精度噪声混进 <0.02 的效应 |
| head 初始化 | **两阶段**：先在冻结 `h_V` 上把 `g_ψ` 训到收敛，再联合训 | 随机初始化的 head 会在最初若干步把乱梯度灌进 encoder |
| seed | 固定；`randn` 两臂共用 | 见 §5.3 |

**🔴 诚实性声明**：E-1/E-2 是**看着 3 个 assay 的 `ρ` 选超参**，而 BindingGYM **没有 dev split 也造不出来**
⇒ 这是 test-set tuning 的一种。缓解：① 主实验用**单一共享超参**，不逐 assay 调；
② pilot 的 3 个 assay 与 M1 的 14 个**重叠**，任何对外数字旁必须标注。
